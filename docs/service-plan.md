# Guide-trip 서비스 기획서

## 1. 서비스 개요

Guide-trip은 가족 여행자가 여행 지역을 정하면 지도 위에서 추천 장소, 저장 장소, 숙소, 이동 동선, AI 이미지 가이드북을 한 화면에서 관리하는 모바일 우선 여행 도구다. 초기 버전은 일본/한국 여행을 중심으로 동작하며, 사용자는 로그인 후 지역과 여행 기간을 저장하고 필요할 때마다 AI 가이드북 이미지를 생성해 볼 수 있다.

## 2. 핵심 가치

- 여행 지역을 먼저 정하고, 그 지역 중심으로 추천 장소를 바로 본다.
- 여행 구성원과 일정은 나중에 등록해도 되며, 등록하면 AI 추천 문구와 가이드북 조건에 반영한다.
- 지도, 추천 리스트, 저장 장소, 길찾기, 숙소 등록을 하나의 바텀시트 인터페이스로 제공한다.
- AI 가이드북은 일반 텍스트가 아니라 A4 가로 여행잡지/인포그래픽 스타일 이미지 2~3장으로 제공한다.
- Google Cloud API 비용 의존을 제거하고, 개발 단계에서는 OpenStreetMap 지도와 AI/로컬 후보 기반 추천으로 운영한다.

## 3. 대상 사용자

- 가족 단위 일본/한국 자유여행자
- 여행지에서 바로 볼 수 있는 모바일 지도형 일정 도구가 필요한 사용자
- 장소를 찾고 저장하고, 숙소 기준 이동 시간을 빠르게 비교하고 싶은 사용자
- 완성형 이미지 가이드북을 받아 여행 전에 공유하거나 저장하고 싶은 사용자

## 4. 사용자 흐름

1. 사용자는 로그인 화면에서 이메일/비밀번호로 로그인한다.
2. 최초 진입 시 지역 설정 모달에서 여행 지역을 입력한다.
3. 지역이 저장되어 있으면 다음 진입부터 바로 지도와 추천 리스트를 본다.
4. 구성원과 여행 기간은 별도 메뉴에서 등록한다.
5. 추천 리스트에서 장소 카드를 열어 상세 팝업을 확인한다.
6. 마음에 드는 장소는 저장한다.
7. 숙소를 등록하면 길찾기 출발지로 사용할 수 있다.
8. AI 가이드북 메뉴에서 생성 버튼을 누르면 저장된 지역과 기간으로 이미지 가이드북 생성 요청이 등록된다.
9. Codex 로컬 처리 또는 향후 OpenAI API 처리 결과가 Supabase에 업로드되면 사이트에서 이미지가 노출된다.
10. 사용자는 각 가이드북 이미지를 원본 파일로 다운로드한다.

## 5. 주요 기능

### 로그인/회원가입

- 이메일, 비밀번호 기반 로그인
- 회원가입은 이메일, 비밀번호, 비밀번호 확인, 휴대폰 번호 입력
- 이메일 인증은 개발 단계에서 사용하지 않음
- 사용자별 여행 상태는 Supabase Auth 사용자 기준으로 분리

### 지역 설정

- 최초 1회 지역 설정 모달 노출
- 이후 검색 메뉴에서 지역 변경 가능
- 지역 변경 시 추천 리스트와 AI 가이드북 상태를 해당 지역 기준으로 갱신

### 지도

- Leaflet + OpenStreetMap 타일 사용
- Google Cloud Maps API 사용 안 함
- 지역 중심, 현재 위치, 숙소, 추천 장소, 저장 장소 마커 표시
- 경로는 실시간 경로 API 없이 직선거리 기반 예상 이동시간으로 표시

### 추천 장소

- 지역 중심과 카테고리 기반 후보 생성
- DeepSeek API가 후보를 가족 여행 관점으로 정리
- Google Places 상세/사진/리뷰 호출은 사용하지 않음
- 카드에는 장소명, 요약, 추천 항목, 예상 가격, 거리 표시

### 장소 상세

- 장소 기본 설명, 추천 이유, 예상 가격, 방문 팁, 판매 메뉴/상품 표시
- 저장/길찾기/외부 지도 보기 버튼 제공
- 외부 지도 보기는 OpenStreetMap 링크 사용

### 저장 장소

- 사용자별 Supabase 또는 로컬 상태에 저장
- 저장 리스트에서도 추천 리스트와 같은 카드 UI 사용
- 상세 닫기 시 저장 리스트로 복귀

### 숙소 등록

- 숙소명 또는 주소를 입력해 후보로 등록
- 등록된 숙소는 길찾기 출발지로 사용
- 헤더 상태 색상으로 등록 여부 표시

### AI 가이드북

- 사용자가 생성 버튼을 누를 때만 요청 생성
- 지역, 여행 시작일, 종료일, 기간 정보를 조건으로 사용
- 이미지 2~3장을 Supabase Storage에 저장 후 노출
- 각 이미지는 원본 파일로 개별 다운로드 가능
- 개발 단계는 Codex 로컬 처리, 상용 단계는 OpenAI API 또는 별도 이미지 생성 워커로 전환 예정

## 6. 운영 정책

- Google Cloud API는 사용하지 않는다.
- OpenStreetMap 타일 정책을 준수해야 하며, 트래픽 증가 시 자체 타일 서버 또는 유료 지도 타일 공급자를 검토한다.
- AI 추천 정보는 실제 영업시간/가격을 보장하지 않으며, 방문 전 확인 안내가 필요하다.
- AI 가이드북 이미지는 생성 시간이 길 수 있으므로 5~10분 안내를 유지한다.

## 7. 향후 기획 과제

- 실제 장소 데이터 품질을 높이기 위한 저비용 데이터 소스 검토
- Nominatim, OpenTripMap, Wikidata, 일본 지역 관광 오픈데이터 등 후보 비교
- 추천 장소 정확도 개선을 위한 사용자 저장/선택 피드백 학습
- AI 가이드북 상용 워커 구조 설계
- 사용자별 여행방 공유, 공동 편집, 초대 기능
- 비용 추적 대시보드와 API 사용량 제한
